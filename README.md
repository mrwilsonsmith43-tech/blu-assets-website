# Blu-Assets Firm Website

Official website for Blu-Assets Firm - a leading investment management company.

## Features

- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Modern UI**: Professional gradient design with blue color scheme
- **Key Sections**:
  - Hero section with call-to-action
  - About company information
  - Services offered
  - Portfolio statistics and track record
  - Contact form for client inquiries

## File Structure

```
├── index.html      # Main HTML file
├── styles.css      # Styling and responsive design
├── script.js       # Interactive functionality
└── README.md       # This file
```

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Or deploy to a web hosting service

## Customization

### Update Company Information
Edit the following in `index.html`:
- Company name and tagline in the hero section
- About section text
- Services descriptions
- Statistics in the portfolio section

### Modify Colors
Edit the color values in `styles.css`:
- Primary blue: `#1e3c72` and `#2a5298`
- Accent cyan: `#00d4ff`

### Add More Content
Add new sections by following the existing HTML structure and CSS patterns.
